## 1. Intention de la séance

La séance 05 ouvre le Module 02.

Elle fait entrer les candidats dans le pilotage de l'IA par les prompts.

L'objectif n'est pas d'écrire de belles phrases à l'IA.

L'objectif est d'apprendre à formuler une demande claire pour obtenir une production utile, contrôlable et améliorable.

Message central :

```text
Un prompt n'est pas une question jetée à l'IA.
Un prompt est une consigne de production.
```

---

## 2. Objectif pédagogique

À la fin de la séance, le candidat doit être capable de :

- reconnaître une demande vague ;
- comprendre pourquoi une demande floue produit souvent une réponse floue ;
- transformer une demande vague en prompt simple ;
- préciser le public, le résultat attendu et le format de réponse ;
- produire un premier fichier de prompt dans son dossier candidat.

---

## 3. Message d'ouverture

```text
Aujourd'hui, nous apprenons à parler à l'IA comme à un assistant de production.

Si la demande est floue, la réponse sera souvent floue.
Si la demande est cadrée, la réponse devient plus utile.
```

Dans l'atelier LN-IA, un prompt sert à produire.

Il doit donc aider l'IA à comprendre :

- le rôle attendu ;
- le contexte ;
- l'objectif ;
- les contraintes ;
- le format de réponse ;
- le contrôle humain nécessaire.

---

## 4. Formule simple à retenir

```text
Rôle + Contexte + Objectif + Contraintes + Format + Contrôle
```

Cette formule n'est pas une règle compliquée.

Elle sert seulement à éviter les demandes trop vagues.

---

## 5. Démonstration

### Demande vague

```text
Fais-moi un texte sur l'IA.
```

Cette demande est trop générale.

Elle ne précise pas :

- le public ;
- le type de texte ;
- l'objectif ;
- le ton ;
- le format ;
- l'usage final.

### Demande cadrée

```text
Tu es formateur en intelligence artificielle pratique.

Rédige un message WhatsApp court pour annoncer un atelier IA à des débutants.

Le ton doit être clair, motivant et professionnel.

Le message doit contenir :
- un objectif ;
- une promesse réaliste ;
- un appel à l'action.
```

Cette demande est plus utile parce qu'elle donne une mission précise à l'IA.

---

## 6. Exercice 1 - Identifier une demande vague

Choisissez une demande vague liée à votre activité.

Exemples :

```text
Aide-moi à écrire un message.
Fais-moi un document.
Donne-moi des idées.
Explique-moi l'IA.
Prépare-moi un plan.
```

Écrivez votre demande vague ici :

```text
Ma demande vague :
...
```

---

## 7. Exercice 2 - Transformer la demande vague en prompt clair

Complétez le modèle suivant :

```text
Rôle :
Tu es ...

Contexte :
Je travaille sur ...

Objectif :
Je veux produire ...

Contraintes :
- ...
- ...
- ...

Format attendu :
Réponds sous forme de ...

Contrôle :
Signale les points que je dois vérifier moi-même.
```

---

## 8. Prompt à copier

Utilisez ce prompt pour vous aider à améliorer votre demande :

```text
Tu es un assistant pédagogique du Challenge 100 jours - Formation IA pratique.

Voici ma demande vague :
[coller ici ma demande vague]

Aide-moi à la transformer en prompt clair et utile.

Le prompt doit contenir :
1. un rôle pour l'IA ;
2. un contexte ;
3. un objectif précis ;
4. trois contraintes ;
5. un format attendu ;
6. une phrase de contrôle humain.

Contraintes :
- garder mon intention ;
- rester simple ;
- ne pas promettre de résultat garanti ;
- produire une consigne directement utilisable.

Format attendu :
Prompt amélioré :
...

Pourquoi ce prompt est meilleur :
...

Points à vérifier par moi-même :
...
```
