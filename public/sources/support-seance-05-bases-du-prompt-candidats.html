1. Présentation de la séance

La séance 05 ouvre le Module 02 et fait entrer les candidats dans le pilotage de l'IA par les prompts.

L'objectif n'est pas d'écrire de belles phrases à l'IA. L'objectif est d'apprendre à formuler une demande claire pour obtenir une production utile, contrôlable et améliorable.

Message central 
Un prompt n'est pas une question jetée à l'IA.
Un prompt est une consigne de production.

2. Méthode de travail

La méthode de la séance conserve la structure LN-IA : comprendre, produire, contrôler, classer et prouver.

Comprendre Partir d'une demande vague et repérer ce qui manque.
Produire Transformer la demande en prompt simple et utilisable.
Contrôler Vérifier que la réponse IA reste utile, claire et exploitable.
Formule à retenir 
Rôle + Contexte + Objectif + Contraintes + Format + Contrôle

3. Objectif pédagogique

À la fin de la séance, le candidat doit être capable de :

  • reconnaître une demande vague ;
  • comprendre pourquoi une demande floue produit souvent une réponse floue ;
  • transformer une demande vague en prompt simple ;
  • préciser le public, le résultat attendu et le format de réponse ;
  • produire un premier fichier de prompt dans son dossier candidat.

4. Message d'ouverture

Texte d'ouverture 
Aujourd'hui, nous apprenons à parler à l'IA comme à un assistant de production.

Si la demande est floue, la réponse sera souvent floue.
Si la demande est cadrée, la réponse devient plus utile.

Dans l'atelier LN-IA, un prompt sert à produire. Il doit aider l'IA à comprendre le rôle attendu, le contexte, l'objectif, les contraintes, le format de réponse et le contrôle humain nécessaire.

5. Démonstration

On part d'une demande vague, puis on la transforme en demande cadrée.

Demande vague 
Fais-moi un texte sur l'IA.
Demande cadrée 
Tu es formateur en intelligence artificielle pratique.

Rédige un message WhatsApp court pour annoncer un atelier IA à des débutants.

Le ton doit être clair, motivant et professionnel.

Le message doit contenir :
- un objectif ;
- une promesse réaliste ;
- un appel à l'action.

7. Exercice 2 - Transformer la demande

Complétez le modèle suivant pour passer de l'idée floue à une consigne de production.

Modèle de prompt simple

Tu es ...

Contexte :
Je travaille sur ...

Objectif :
Je veux produire ...

Contraintes :
- ...
- ...
- ...

Format attendu :
Réponds sous forme de ...

Contrôle :
Signale les points que je dois vérifier moi-même.

8. Prompt à copier

Ce prompt aide le candidat à améliorer sa demande vague en prompt clair.

Prompt d'amélioration 
Tu es un assistant pédagogique du Challenge 100 jours - Formation IA pratique.

Voici ma demande vague :
[coller ici ma demande vague]

Aide-moi à la transformer en prompt clair et utile.

Le prompt doit contenir :
1. un rôle pour l'IA ;
2. un contexte ;
3. un objectif précis ;
4. trois contraintes ;
5. un format attendu ;
6. une phrase de contrôle humain.

Contraintes :
- garder mon intention ;
- rester simple ;
- ne pas promettre de résultat garanti ;
- produire une consigne directement utilisable.

Format attendu :
Prompt amélioré :
...

Pourquoi ce prompt est meilleur :
...

Points à vérifier par moi-même :
...
