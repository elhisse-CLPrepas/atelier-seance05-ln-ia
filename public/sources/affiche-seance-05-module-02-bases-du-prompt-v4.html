Passer du flou à une consigne claire

Apprendre à formuler une demande utile, contrôlable et améliorable pour produire avec l'IA.

Formule :
Rôle + Contexte + Objectif + Contraintes + Format + Contrôle
Réflexe Module 02 :
cadrer avant de demander, produire une première version, corriger avant de valider.

Objectif de la séance

Comprendre pourquoi une demande vague produit souvent une réponse vague, puis transformer cette demande en prompt simple et exploitable.

Objectif du Module 02

Entrer dans le pilotage de l'IA par les prompts : demander clairement, contrôler la réponse et classer les preuves de travail.

Ordre du jour

  1. 1Ouverture : parler à l'IA comme à un assistant de production.
  2. 2Démonstration : comparer une demande vague et une demande cadrée.
  3. 3Exercice 1 : identifier une demande vague liée à son activité.
  4. 4Exercice 2 : transformer la demande en prompt clair.
  5. 5Livrable : créer ou compléter son premier fichier de prompt.

Les 6 éléments à installer

01Donner un rôle à l'IA
02Présenter le contexte
03Préciser l'objectif
04Ajouter les contraintes
05Fixer le format attendu
06Garder le contrôle humain

Un prompt n'est pas une question jetée à l'IA.
C'est une consigne de production.
